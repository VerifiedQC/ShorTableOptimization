How the record is built

One row per level of the recursion. The record is a composite: each level may use a different submitted table, so credit is shared.

    What is being measured

    The ranked quantity is the logical gate count of a recursive phase product on two 2048-bit operands. Lower is better.

    Costs are charged per operation at the width that operation runs at: an addition costs 2 × (9w − 16) gates and a negation 2 × (10w − 14), each charged twice because one symbolic operation acts on both operands. Shifts are free. The recursion stops at a schoolbook base case costing 5w². Sign-extension bookkeeping is charged per node.

    These are closed-form charges, not a count of a compiled circuit. They match the companion development's circuit-level count wherever that count is computable; it does not run at these widths. Depth is not charged, so a table is ineligible if it is deeper than the current per-target champion at the same arity.

    Every table in the plan compiles against a fixed Lean specification with its correctness proofs, and the audit admits propext alone. See the per-target benchmark for how tables are accepted and scored individually.
